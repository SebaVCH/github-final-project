# Simple Interest Calculator

## 📌 Project Name
**Simple Interest Calculator** — Proyecto Final: Introducción a Git y GitHub

## 📖 Description
Este proyecto consiste en una calculadora de **interés simple** desarrollada como script de Bash. El script solicita al usuario el capital (principal), la tasa de interés (rate of interest) y el período de tiempo (time period), y calcula el interés simple utilizando la fórmula:
Simple Interest = (Principal × Rate × Time) / 100


El proyecto también incluye los archivos estándar de un repositorio de código abierto: licencia Apache 2.0, código de conducta, guía de contribución y este README.

## 🎯 Objetivo
Demostrar el uso de **Git**, **GitHub** y la **línea de comandos (Git CLI)** mediante la creación, bifurcación (fork), gestión de ramas, fusión (merge) y solicitudes de extracción (pull requests) de un repositorio público.

## 🚀 Cómo usar el script

### Requisitos previos
- Sistema operativo tipo Unix (Linux, macOS o WSL en Windows)
- Bash
- `bc` (calculadora de precisión arbitraria) instalado

### Instalación y ejecución
1. Clona el repositorio:
   git clone https://github.com/[TU_USUARIO]/[TU_REPOSITORIO].git
2. Entra al directorio:
cd [TU_REPOSITORIO]

3. Da permisos de ejecución al script:
chmod +x simple-interest.sh

4. Ejecuta el script:
./simple-interest.sh
